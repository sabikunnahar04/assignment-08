# BookNook – Online Library Management System

**Live Website:** https://booknook-weld.vercel.app/

BookNook is an online library management platform where users can explore books, borrow their favorite reads, and manage their personal book collections. It provides a simple and user-friendly reading experience.

## Features

- **Browse Books:** Explore all available books with their title, author, category, and cover image.
- **Book Details:** View detailed information about each book before borrowing.
- **User Authentication:** Register and log in using email and password or Google.
- **Add Books:** Logged-in users can add new books to the library.
- **Manage My Books:** Users can view, update, and delete the books they have added.
- **Borrow Books:** Borrow available books through a simple borrowing process.
- **My Borrows:** View borrowed books and return them when finished.
- **New Arrivals:** Discover the latest books added to the library.
- **Responsive Design:** Enjoy a user-friendly experience across desktop, tablet, and mobile devices.
- **Interactive Banner:** Explore featured slides with automatic transitions and navigation controls.
